
# Zepto Inventory Analysis | Python & Power BI

## Project Overview

This project analyzes Zepto inventory data using Python for data cleaning and Power BI for dashboard development. The dashboard provides insights into inventory value, product availability, stock status, category-wise discounts, and pricing patterns.

## Dashboard Screenshot

![Zepto Inventory Dashboard](zepto%282%29.jpg)

## Key Features

- Inventory value and product count analysis.
- Low-stock and out-of-stock monitoring.
- Category-wise discount analysis.
- Pricing comparison and inventory insights.
- Interactive filters for exploring inventory data.

## Tools Used

- Python (Pandas) for data cleaning.
- Microsoft Power BI for dashboard development.
- Data Visualization.
